# WELFARE INTELLIGENCE
### AI-Based Predictive Personnel Stress & Welfare Monitoring System for Uniformed Forces

A next-generation enterprise frontend designed for authorized welfare and command personnel to monitor personnel stress, circadian fatigue, workload saturation, and proactive wellness indicators using predictive AI analytics.

---

## 🌟 Key Highlights

- **Aesthetic**: Dark AI Command Center + Human Welfare Tech (Deep navy, cyber cyan, violet highlights, emerald/amber/rose risk badges, glassmorphism, glowing borders).
- **Ethical Foundation**: Strictly **support > punishment**, **prevention > reaction**, non-punitive language, pseudonymous tactical IDs, and human-in-the-loop decision support.
- **11 Full Navigation Modules**:
  1. **Overview Dashboard**: 5 KPI cards with SVG sparklines, AI Predictive Risk Donut (94.2% confidence), Stress Trend Line Chart (24h/7d/30d), Fatigue Risk distribution bars, Personnel Requiring Attention table, Early Warning Center, Recommended Interventions.
  2. **Personnel Directory**: Live multi-field search, formation filters, risk classification filters, sortable columns, and full Personnel Wellness Profile modal drill-down.
  3. **AI Risk Prediction**: Horizon projections (24h, 72h, 7d, 14d, 30d), SHAP feature importance weights, and ethical safeguards.
  4. **Stress Analytics**: 5 multi-filters controlling 6 charts (Stress trend, Fatigue velocity, Recovery capacity, Workload vs. Stress correlation, Risk band census, Formation comparisons).
  5. **Fatigue Monitoring**: Circadian rhythm tracking, sleep deficit telemetry, 12-hour rest buffer tracking, and 72-hour AI exhaustion forecast.
  6. **Welfare & Support Center**: Confidential 1-on-1 check-ins, mental wellbeing resource library, peer support network, clinical counseling referrals, sleep optimization blueprints, and official Military Confidentiality Notice.
  7. **Alert Center**: Live triage stream with filterable severities and interactive **Acknowledge**, **Investigate**, and **Resolve** action workflows.
  8. **Intervention Center**: Lifecycle tracking across Recommended, Scheduled, In Progress, and Completed states, with an interactive audit timeline.
  9. **Reports & Insights**: Executive dossiers with working simulated **PDF Export** and **CSV Analytics Export**.
  10. **AI Assistant**: Natural language welfare query assistant with suggested question chips, streaming simulation, structured metrics, and data tables.
  11. **Settings & Privacy**: Role-based access control (RBAC), data anonymization toggles, threshold sensitivity sliders, and immutable security audit ledgers.

---

## 🚀 Hackathon Presentation Features

- **Presentation Mode**: 1-click toggle in the top navbar that collapses the sidebar, maximizes widescreen chart visibility, and surfaces a quick tab bar for judge presentations.
- **Judge Pitch Brief**: Dedicated modal in the navbar outlining the core mission, hybrid LSTM/GBDT architecture, SHAP attribution, ethical charter, and demo script.
- **Live Telemetry Simulator**: Toggleable switch that streams real-time biometric telemetry pings and dynamic early warnings.
- **Audio-Haptic Sound Effects**: Built-in procedural Web Audio synthesizer providing subtle sci-fi clicks, alert notifications, and resolution chimes (with 1-click mute toggle).
- **Mobile Responsive Drawer**: Accessible on phones and tablets via a sliding drawer navigation.
- **Authentication Gateway**: High-tech cyber shield login with pre-filled credentials and a 1-click *"Enter Demo as Welfare Administrator"* button.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4 + Custom Cyber Glassmorphism
- **Icons**: Lucide React
- **Data Visualization**: Recharts + Custom SVG Sparklines & Gauges
- **Audio Engine**: Web Audio API (Procedural synthesizer)

## 💻 Quick Start

```bash
# Navigate to project directory
cd "welfare-intelligence"

# Install dependencies (already completed)
npm install

# Start development server
npm run dev

# Open in browser
http://localhost:5173/
```

To build for production:
```bash
npm run build
```

## ⚖️ Ethical Welfare Disclaimer
The system provides predictive indicators as non-clinical decision support for authorized welfare supervisors. All indicators are designed to facilitate early rest, recovery buffers, and supportive counseling, and are strictly segregated from disciplinary evaluations.
